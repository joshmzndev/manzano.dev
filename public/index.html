Scripts

Personal scripts, served raw so they can be fetched with curl or wget.

curl -fsSLO https://example.com/<script>

Setup

setup.sh
Updates apt, installs git with stored credentials, and installs Claude Code. 
curl -fsSL https://example.com/setup.sh | bash

Backups

backup.sh
Encrypted rclone backups of local folders to Google Drive, an organize command that sorts stray media and documents, and a systemd timer for hourly runs. Commands: setup, check, organize, backup, install. 
cd ~ && curl -fsSLo backup.sh https://example.com/backup.sh && chmod +x backup.sh
backup_secrets.sh
Encrypts ~/.config files, ~/.ssh and the GPG keyring with age (passphrase) into config.age, ssh.age and gpg.age.
restore_secrets.sh
Reverses backup_secrets.sh: decrypts the .age files in the current folder and restores them under ~.

FreeRADIUS

mac_add.py
Adds a MAC address (any common format) to the FreeRADIUS users file and reboots. Supports --dry-run, --no-reboot and --users-file. 
sudo python3 mac_add.py AA:BB:CC:DD:EE:FF --dry-run
read_log.py
Tails a log file and reports MAC addresses that aren't yet authorized in FreeRADIUS. 
python3 read_log.py /var/log/freeradius/radius.log

Windows

get_windows_key.bat
PowerShell one-liner that prints the OEM Windows product key stored in firmware.
